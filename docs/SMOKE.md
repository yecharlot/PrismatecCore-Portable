# Prueba de humo (servicio)

1. `scripts/build-windows.ps1` (o build-linux.sh).
2. `start.bat` / `./start.sh`.
3. Abrir Desktop → ÁbacoPhy → login (LOGIN.md del repo AbacoPhy).
4. Studio → cargar ejemplo → preview móvil/tablet/desktop.
5. Nodo `/studio/` responde.
6. Crear dato en AbacoPhy, reiniciar procesos, comprobar que sigue en `data/tenants/abacophy`.
